# Synthaea

Synthaea is an open-source, multi-platform EDR/XDR with on-device ML detection.

Status (from the `edr` README): the Linux pipeline runs end to end on kernel telemetry. The remaining platforms and the control plane are planned in the repository roadmap.

## Public repositories

- [edr](https://github.com/synthaea-lab/edr): Open-source, multi-platform EDR/XDR with on-device ML detection.
